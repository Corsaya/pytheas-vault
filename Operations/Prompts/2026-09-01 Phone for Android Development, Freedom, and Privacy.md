# Prompt

what is the best phone for app development, freedom, and privacy. Future and current

# Result

Recommendation: buy a factory-unlocked Pixel 10 (256 GB if it will hold local builds, media, and offline data) and install GrapheneOS yourself. It is the strongest current one-phone compromise: official GrapheneOS production support, Android/ADB hardware testing, an unlockable bootloader, and a long support window through August 2032.

Do **not** buy a Pixel 11 for GrapheneOS yet. It is newer, but GrapheneOS has not added official production support and its developers are assessing whether the hardware meets their security standards. Reassess only once official support is published.

For serious Android releases, retain or borrow a second device running stock Android (and add an iPhone only if shipping iOS). A GrapheneOS daily driver is a useful hostile/permission-restricted test target, but it does not replace testing the stock Google stack or other OEMs.

Alternatives were deliberately not chosen: Fairphone offers stronger repairability and bootloader freedom but is not a GrapheneOS target; Linux phones maximize hackability but are poor primary targets for mainstream Android app development and daily reliability.

Sources consulted: GrapheneOS device-support FAQ and features/usage documentation; Android Developers hardware-device testing documentation; Google Pixel update-support documentation; Fairphone bootloader documentation.
